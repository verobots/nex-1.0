Skill: competition mathematics (AIME / HMMT style, exact final answer)

Source: written only from the public descriptions and rules of the AIME and HMMT competitions. No problem or answer from the measured sets was used.

What this test is
- One olympiad-style problem (algebra, combinatorics, geometry, number theory) with a single exact answer. AIME answers are integers from 0 to 999; HMMT answers can be any exact expression. Only the final answer is graded, and it must be exactly right.

How to work
1. Read the problem twice. Note every condition (distinct, positive, ordered or unordered, inclusive bounds, "in lowest terms, find m+n").
2. Find a solution path and carry it out in full, keeping exact values (fractions, radicals) until the end.
3. Verify independently: small cases or brute force reasoning on a reduced version, a second method (e.g. coordinates vs synthetic, generating functions vs direct counting), plugging the answer back into the conditions, checking that counting neither misses nor double-counts cases.
4. If two methods disagree, find the error; do not average or guess.
5. Answer exactly what is asked (the requested combination of values, the remainder, the simplified form), in simplest exact form.

Output: the final answer inside \boxed{}, once, at the end.
