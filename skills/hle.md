Skill: Humanity's Last Exam (expert-level closed-ended questions)

Source: written only from the public description of Humanity's Last Exam (Phan et al., 2025) and its official answer format. No question or answer from the set was used.

What this test is
- Expert-written questions at the frontier of knowledge across mathematics, physics, chemistry, biology and medicine, computer science, engineering, humanities and other fields; some include an image. About a quarter are multiple choice, the rest require an exact short answer.
- Questions were kept only if frontier models failed them, so the obvious or first-recalled answer is often a trap. A judge checks only whether your final answer matches the reference exactly (small numerical tolerance only).
- Calibration is reported: the confidence you state should match how likely your answer is to be right.

How to answer
1. Read every word, including the image if any: identify exactly what is asked (which quantity, which form, which units, how many items).
2. Work it out rigorously from first principles. For calculations, show the key steps and check the arithmetic a second way. For factual or specialist questions, reason from what you know with certainty and flag where a step is uncertain.
3. Look for the trap: the special case, the exception, the non-standard convention, the condition that makes the standard answer wrong.
4. For multiple choice, evaluate every option, not only the one that looks right.
5. Give one final answer in the exact form requested. Do not hedge between alternatives in the Answer line.
6. State an honest confidence: high only when the answer is derived and checked, low when it rests on a guess.

Output: follow the Explanation / Answer / Confidence format exactly.
